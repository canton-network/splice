The button is wrapped in `DisableConditionally` (disabled while `nameLookupStatus === 'loading'`), which renders the bare child when enabled and `<Stack><Tooltip><span>child</span></Tooltip></Stack>` when disabled, so each loading toggle remounts the button.

Options:
- frontend: let `DisableConditionally` render the same tree in both states, so its buttons keep their DOM node
- test: press Enter in `entry-name-field` (same handler) instead of clicking the button

Retrying only the click could hit the disabled button, which Selenium clicks without error and without effect.
