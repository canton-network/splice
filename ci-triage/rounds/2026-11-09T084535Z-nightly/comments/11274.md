The run did exclude the tag (`-l org.lfdecentralizedtrust.splice.util.scalatesttags.SpliceAmulet_0_1_25`). Scalatest 3.2.19 reads class tags with `Class.getAnnotations`, which only returns a superclass annotation if it is `@Inherited`. This was the first nightly with canton-network/splice#8224; the previous one passed. It will fail every night until fixed (TrafficBasedRewardsTimeBasedIntegrationTest has the same problem; it also ran in this run, in another shard, and failed there on an unrelated leftover environment first).
