UnclaimedActivityRecordIntegrationTest (An UnallocatedUnclaimedActivityRecord gets expired) on main d852f3c54c, wall-clock-time (4), failed its first check:

```
Check vote request and UnallocatedUnclaimedActivityRecord have been created for Creating vote request List() was empty UnallocatedUnclaimedActivityRecord (UnclaimedActivityRecordIntegrationTest.scala:109)
```

The test builds the vote request with an expiry of `Instant.now().plus(5, ChronoUnit.SECONDS)` for the record (15:37:48.15, so about 15:37:53.15). Creating the vote request took 5 s (ingested at 15:37:53.136), and when CloseVoteRequestTrigger executed it at 15:37:53.74 the record was already expired:

```
15:37:53.756 ... AssertionFailed: The requirement 'UnclaimedActivityRecord expires after current time' was not met.
    in choice ...:Splice.DsoRules:DsoRules:DsoRules_CreateUnallocatedUnclaimedActivityRecord on contract 0077d68c18 (#4)
    in choice ...:Splice.DsoRules:DsoRules:DsoRules_CloseVoteRequest on contract 0077d68c18 (#0)
```

The trigger retried the same action until the test ended, so the record was never created.
