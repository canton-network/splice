## Cause: precompiled classes cache miss, full compile inside the 40 min budget

```
grep -a -A60 'Run ./.github/actions/cache/precompiled_classes/restore' log/10681/job.txt | grep -a 'Cache not found'
Cache not found for input keys: classes-10 branch:main dependencies:1e63be93ab66642d3f0837bd5a8e3d190b9807dc81a5848427a5f3957f18e557 rev:57f9f8e2cc..., classes-10 branch:main dependencies:1e63b...
```
The run before (66d24625eb, run 40500749694, 10679) restored `dependencies:c9957cb1...`. Only one commit between them:
```
git log --oneline 66d24625eb..57f9f8e2cc
57f9f8e2cc Don't document overlapping record times across migrations in scan.yaml (#7989)
git show --stat 57f9f8e2cc | tail -2
 apps/scan/src/main/openapi/scan.yaml | 15 ++++++---------
```
The cache key hashes `openapi-cache-key.txt` (`common_setup.sh:63`: sha256 of every `*/openapi/*.yaml`), so an
openapi edit changes `dependencies:`; restore-keys only fall back to the same `dependencies:` hash, so nothing restores.

Timeline (10681, job log timestamps):
```
13:27:01 welcome to sbt 1.12.14
13:29:11 compiling 264 Scala sources to .../canton/community/admin-api/target/scala-2.13/classes   (everything from scratch)
13:38:55 compiling 237 Scala sources to .../apps/app/target/scala-2.13/test-classes
13:40:05 No tests to run for tools / Test / testOnly    (tests start)
14:07:01 Killed SBT after timeout 40m
```
With a cache hit (10679, same shard layout): sbt 12:12:27, test compile done 12:18:08, i.e. ~6 min instead of ~13 min.
The ~7 min extra compile comes out of the test budget; shards near the budget get killed.

## Fix options (CI, not tests)
- Add a broader restore key `classes-<v> branch:main` (no dependencies hash) so zinc recompiles incrementally from the
  previous main cache instead of from scratch; or
- compile (`Test/compile`) in its own step before the timed `testOnly`, so the 40 min only covers tests.
Same mechanism hit #7969's wall-clock (0) on 2026-10-26/27 (Dependencies.scala change).
