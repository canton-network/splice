## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Docker images

    - Upgrade base image to 1.0.19

  - Validator App

    - `synchronizer-topology.num-parties` metric now includes also parties not hosted on any participant. This also fixes an issue where those were deducted from the metric on update,
      but then inconsistently added back in an app restart.

  - SV App

    - Joining SVs now download the DSO party ACS from their sponsor as a file instead of receiving it in memory.
      This supports large snapshots.
      The new `/v0/onboard/sv/party-migration/prepare` and `/v0/onboard/sv/download/{id}` endpoints are annotated
      with `x-external-audience: svs`, so SVs restricting SV app ingress must expose them.
      Sponsoring SVs must upgrade to this version before they can onboard SVs that run it.
      Both SVs store the snapshots in `canton.sv-apps.sv.onboarding-snapshots.directory`, which defaults to a
      temporary directory and should point to a volume with enough free space.
