## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - SV App

    - Joining SVs now download the DSO party ACS and sequencer onboarding state from their sponsor as files
      instead of keeping the responses in the SV app's memory, reducing SV app memory usage for large
      snapshots. SVs that restrict SV app ingress must allow other SVs to reach the new
      `/v0/onboard/sv/party-migration/prepare`, `/v0/onboard/sv/sequencer/prepare` and
      `/v0/onboard/sv/download/{id}` endpoints, which are tagged `x-external-audience: svs`.

  - Deployment

    - SV onboarding snapshots are kept in `canton.sv-apps.sv.onboarding-snapshots.directory`, a new required setting
      that must point to persistent storage. The SV Helm chart now always creates a dedicated 35 GiB
      `onboardingSnapshotsPvc` for it, mounted at `/onboarding-snapshots`.
