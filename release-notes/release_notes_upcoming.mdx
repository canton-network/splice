## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Scan App

    - Removed the internal `/v0/transfer-command-counter/{party}` and `/v0/transfer-command/status` endpoints.
      Most of the deprecated TransferCommand functionality has already been removed in splice 0.8.0, this removes
      the remaining parts.

  - Validator App

    - Removed the `/v0/scan-proxy/transfer-command-counter/{party}` and `/v0/scan-proxy/transfer-command/status`
      endpoints. Most of the deprecated TransferCommand functionality has already been removed in splice 0.8.0,
      this removes the remaining parts.

  - Deployment

    - The SV charts (`splice-sv-node`, `splice-scan`, `splice-global-domain` and `splice-splitwell-app`) now honour
      `persistence.user` and `persistence.bootstrapDatabaseName`, as the validator and participant charts already do. The
      `pg-init` and wait containers, the Postgres exporter sidecar and the mediator and sequencer nodes themselves no
      longer hardcode the `cnadmin` role and the `cantonnet` bootstrap database. They default to those values, so
      rendered output is unchanged unless you set them.
