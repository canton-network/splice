## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Docker images

    - Upgrade base image to 1.0.19

  - Validator App

    - `synchronizer-topology.num-parties` metric now includes also parties not hosted on any participant. This also fixes an issue where those were deducted from the metric on update,
      but then inconsistently added back in an app restart.

  - Governance locks

    - The `cip-127/*` metadata entries (e.g. `cip-127/lock-kind` and `cip-127/lock-status`), which were created by accident in the metadta, are no longer
      written to the metadata of governance lock transfer instructions and of lock transfer and substitution proposals.
      Read the lock information from the `cip-127/memo:` memo in the reason
      (`splice.lfdecentralizedtrust.org/reason`) instead.
