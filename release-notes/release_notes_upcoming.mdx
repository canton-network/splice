## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Scan App

    - The endpoints `POST /v0/events` and `GET /v0/events/{event_id}` now include an optional `round_number` field in
      the `verdict`. This field is present in verdicts recorded after SV operators have enabled it via a `DsoRules`
      configuration update, except on the Scan of a newly onboarded SV for its first rounds. The value of this field
      is the same as the oldest `OpenMiningRound` active at the verdict's `record_time`, which is the same as the
      `round_number` specified in `app_activity_records`.
