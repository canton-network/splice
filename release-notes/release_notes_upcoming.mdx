## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Docker images

    - Upgrade base image to 1.0.19

  - Scan App

    - `/v0/events` responses now include two optional per-event fields:

      - `asset_activity_records`: asset-side activity records parallel to `app_activity_records`.
      - `submitting_app_provider`: the submitting app provider party identifier when the submitter is a featured-app.

    - Two activity-record schemas have been renamed: `AppActivityRecord` → `ActivityRecord` (shared `{party, weight}` type) and `EventHistoryAppActivityRecords` → `EventHistoryActivityRecords`. Wire shape unchanged; generated-client type names differ.

  - Validator App

    - `synchronizer-topology.num-parties` metric now includes also parties not hosted on any participant. This also fixes an issue where those were deducted from the metric on update,
      but then inconsistently added back in an app restart.
