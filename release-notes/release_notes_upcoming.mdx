## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Docker images

    - Upgrade base image to 1.0.19

  - Helm charts

    - The default `initImageName` of the `pg-init` init containers, and the image of the postgres-exporter init container,
      are now `postgres:18.6-trixie`, pinned by digest, instead of `postgres:14`. PostgreSQL 14 reaches end of life on
      2026-11-12. The init containers only use `psql`, which works with any supported server version.

  - Validator App

    - `synchronizer-topology.num-parties` metric now includes also parties not hosted on any participant. This also fixes an issue where those were deducted from the metric on update,
      but then inconsistently added back in an app restart.
