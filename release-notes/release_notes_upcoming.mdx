## Upcoming for next patch release:

{/* Add all release notes in this section */}

  - Scan App

    - Removed the internal `/v0/transfer-command-counter/{party}` and `/v0/transfer-command/status` endpoints.
      Most of the deprecated TransferCommand functionality has already been removed in splice 0.8.0, this removes
      the remaining parts.
    - Removed the deprecated `/v0/amulet-config-for-round` endpoint. Use the `transferConfigUsd` and `amuletPrice`
      fields of the `OpenMiningRound` contracts returned by `/v0/open-and-issuing-mining-rounds` instead.
    - The `DeleteCorruptAcsSnapshotTrigger` is removed because it is obsolete.
    - Scan switches its update history to tables partitioned by record time. On the first start, a database migration
      renames the existing update history tables to `*_legacy` (no data is copied) and creates the new tables. Scan reads
      from both. After this migration, Scan cannot be downgraded to an earlier version.
    - ACS snapshots are now always stored in per-snapshot tables. The `per-acs-snapshot-tables-enabled` setting is
      deprecated: `true` is accepted and has no effect, `false` is rejected at startup. Remove it from your configuration.
    - An SV that joins after the switch cannot backfill update history from other SVs until a later release.
      Its Scan does not create ACS snapshots until then.

  - Validator App

    - Removed the `/v0/scan-proxy/transfer-command-counter/{party}` and `/v0/scan-proxy/transfer-command/status`
      endpoints. Most of the deprecated TransferCommand functionality has already been removed in splice 0.8.0,
      this removes the remaining parts.
